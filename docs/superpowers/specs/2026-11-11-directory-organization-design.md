# 역할별 디렉터리 정리

## 목적

루트에 섞인 내부 구현과 검증 스크립트를 역할별로 분리하여 탐색과 유지보수를 쉽게 한다. 기존 사용자 실행 명령과 기능은 유지한다.

## 검토한 방법

- 최소 정리: 테스트와 문서만 이동한다. 변경은 작지만 내부 구현이 루트에 남는다.
- 역할별 정리: 내부 구현, 검증, 운영 도구를 분리한다. 설치 번들과 참조 경로 수정이 필요하다. 사용자가 이 방법을 선택했다.

## 구조

- 루트: README.md, setup.sh, update.sh, remove.sh 및 저장소 설정.
- lib/: Python 실행 모듈과 toolkit.sh 공통 설치 구현.
- tests/: check_*.py 검증 스크립트.
- tools/mem0_import/: Mem0 가져오기 스크립트와 SQL. 해당 검증 스크립트는 tests/로 이동한다.
- docs/: policy.md와 기존 설계·계획 문서.

## 호환성과 범위

사용자 진입점은 유지한다. 설치 번들은 같은 구조를 사용하며 복사 목록, 런처, 모듈 가져오기, 경로 계산, 정책 읽기, README 명령, 테스트 픽스처를 함께 수정한다. 기존 설치에서 업데이트할 때 새 구조로 전환되는 경로를 확인한다. 기능 추가, 인증 설정 변경, 개인 로컬 캐시 및 무시된 디렉터리 정리는 포함하지 않는다. 열린 PR은 조회 시점에 없으므로 PR 병합이나 삭제는 수행하지 않는다.

## 검증

셸 구문 검사와 기존 오프라인 검증을 실행한다. 실제 사용자 전역 환경을 변경하는 설치·제거는 실행하지 않는다. 참조 검색과 변경 내역으로 이전 경로 잔존을 확인한다.
